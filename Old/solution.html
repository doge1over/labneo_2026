LB Control

Программный комплекс "LB Control" является основой для построения системы учета реактивов, например, в научно-ислеовательских центрах или лабораториях

Наши продукты

LB Control

Возможности

  • Автоматизация учета реактивов
  • Отслеживание сроков годности
  • Проведение инвентаризации
  • Получение актуальной информации о заканчивающихся запасах
  • Контроль доступа сотрудников к разным реагентам
  • Ведение журнала учета реагентов, соответствующего нормативным требованиям

Преимущества

  • Неограниченное количество пользователей
  • Широкая адаптивность программного обеспечения под потребности пользователя
  • Непрерывный мониторинг сроков годности с оповещением пользователей
  • Дополнительно возможен пакет документации по валидации
LB Mini

Размер не имеет значения

  • Идеально подойдет для небольших лабораторий
  • Полный функционал для одного пользователя
  • Можно комбинировать с любыми модулями
  • Возможен пакет документации по валидации

LBReactive
Модуль

Реактивы под контролем

  • Модуль решает задачу автоматизации контроля и учета реактивов
  • LBReactive отслеживает сроки годности, упрощает проведение инвентаризации
  • Предоставляет актуальную информацию о заканчивающихся запасах
  • Позволяет контролировать доступ сотрудников к данным о тех или иных реактивах
  • Дополнительно модуль позволяет вести журнал учета реактивов в формате, соответствующем нормативным требованиям
LBVerification
Модуль

Точность в каждом предмете

  • Модуль создан для упрощения работы с оборудованием
  • Позволяет контролировать сроки поверки оборудования
  • Хранит электронные копии паспортов оборудования и протоколов поверки на каждую единицу
  • За счет введения инвентарного QR-кода, оператор оборудования сможет проверить срок поверки с мобильного устройства
LBSupport
Модуль

Поддержка, на которую можно положиться

  • Модуль позволяет отправлять и контролировать заявки в различные отделы организации
  • Интегрируется с технической или IT-службой
  • Позволяет получать обратную связь о статусе заявки
  • С помощью категоризации видов обращений позволяет пользователю быстро и точно описывать проблемы
LBArchive
Модуль

Надёжное хранение, лёгкий доступ

  • Данный модуль позволяет быстро формировать описи для передачи документов в архив
  • Формирует электронный журнал описей
  • Позволяет искать описи по различным критериям: номер договора, название документа, составитель описи
  • Модуль позволит снизить нагрузку на сотрудников архива

Минимальные требования к аппаратному и программному обеспечению

Для функционирования ПО "LB Control"
  • Процессор (не менее 4 ядер CPU)
  • Оперативная память (не менее 8 Гб)
  • Дисковое пространство (не менее 20 Гб)
  • Операционная система Astra Linux CE/SE, Альт Линукс, РедОС
  • Сетевое соединение со скоростью не ниже 10 Мбит/с
  • Монитор с разрешением не ниже 1024х768
  • Клавиатура, мышь
